# Default branding files

Optional. Drift's White Label defaults use these if they exist; otherwise the
field is simply blank (never a broken image).

| File | Used for | Size |
|---|---|---|
| `drift-admin-bar-logo.png` | Top-left of the admin bar | ~40px tall (shown at 20px) |
| `drift-login-logo.png` | Login screen | 640 × 230 (shown at 320 × 115) |

Per-site logos are set on **Drift → White Label** and override these.
